# M1 — Ordinal por limiares sobre variável latente

**Hipótese.** O avaliador observa y* e atribui o nível k tal que k-0,5 < y* <= k+0,5 (limiares equidistantes).

**Justificativa.** Reflete a escala real de 6 níveis (0,40,...,200) por competência.

**Parâmetros.** sigma_c, sigma_u, sigma_beta; limiares fixos em k±0,5 (premissa).

**Limitações.** Limiares equidistantes são hipótese; níveis reais podem ter 'larguras' diferentes.

**Implicações.** Torna a discrepância mínima observável igual a 40 pontos em uma competência.

_Todos os parâmetros são HIPOTÉTICOS até calibração com dados reais._

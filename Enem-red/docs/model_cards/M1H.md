# M1H — Ordinal com ruído crescente no desempenho (heterocedástico)

**Hipótese.** O ruído cresce com o nível latente: sd = sigma_c*(1 + het_slope*theta/5). Hipótese inspirada no deck (mais subjetividade no topo) — TRATADA COMO HIPÓTESE, não como fato.

**Justificativa.** Permite testar se a instabilidade concentra-se no topo da escala.

**Parâmetros.** sigma_c, sigma_u, sigma_beta, het_slope.

**Limitações.** A forma funcional do crescimento é arbitrária; sem dados não há como validá-la.

**Implicações.** Se resultados no topo só aparecem sob M1H, a conclusão depende da hipótese de heterocedasticidade.

_Todos os parâmetros são HIPOTÉTICOS até calibração com dados reais._

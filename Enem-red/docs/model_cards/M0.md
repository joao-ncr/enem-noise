# M0 — Normal contínua truncada em [0,200]

**Hipótese.** A nota por competência é contínua: 40*y* com ruído gaussiano, truncada em 0..200.

**Justificativa.** Linha de base clássica (teoria clássica dos testes); permite comparar com o modelo discreto.

**Parâmetros.** sigma_c, sigma_u, sigma_beta (em níveis).

**Limitações.** Ignora que a nota real só assume 6 níveis por competência; subestima saltos de 40 pontos.

**Implicações.** Se M0 e M1 divergem nas conclusões, a discretização importa e M0 não deve ser usado sozinho.

_Todos os parâmetros são HIPOTÉTICOS até calibração com dados reais._
